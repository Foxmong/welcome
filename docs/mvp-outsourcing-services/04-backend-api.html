04 Backend/API

백엔드/API 개발 예시

사용자 데이터, 파일 처리, AI 연동, 관리자 기능이 안정적으로 동작하도록 서버와 API를 설계합니다.

서버 구축 예시

구성예시
애플리케이션 서버Next.js API, NestJS, Django, FastAPI 중 프로젝트 성격에 맞게 선택
데이터베이스PostgreSQL 또는 MySQL
파일 저장소S3 호환 스토리지에 음성 파일 저장
작업 큐긴 음성 변환 작업을 비동기로 처리
캐시처리 상태 조회와 반복 요청 완화를 위해 Redis 선택 가능

REST API 예시

MethodEndpoint용도
POST/api/auth/signup회원가입
POST/api/auth/login로그인
GET/api/meetings회의록 목록 조회
POST/api/meetings회의록 생성 요청
GET/api/meetings/:id회의록 상세 조회
PATCH/api/meetings/:id회의록 수정
POST/api/meetings/:id/process음성 변환 및 요약 작업 시작

인증/권한 관리

  • 사용자는 본인 회의록만 조회 가능
  • 관리자는 사용자 목록과 처리 실패 로그 조회 가능
  • 업로드 파일 URL은 임시 접근 URL로 발급
  • 비밀번호는 해시 저장, 세션 또는 JWT 기반 인증 적용
