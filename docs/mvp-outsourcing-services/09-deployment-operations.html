09 Deployment

배포/운영 세팅 예시

개발된 MVP를 실제 사용자가 접속할 수 있도록 도메인, 서버, 보안, 모니터링 환경을 구성합니다.

배포 구성 예시

항목예시
도메인meeting-ai.example.com 연결
프론트엔드Vercel, Netlify, Cloudflare Pages 등
백엔드AWS, GCP, Azure, Render, Fly.io 등
DBManaged PostgreSQL
파일 저장소S3 호환 오브젝트 스토리지
SSLHTTPS 인증서 자동 적용

CI/CD 예시

개발자가 main 브랜치에 병합
 ↓
자동 테스트 실행
 ↓
빌드
 ↓
스테이징 배포
 ↓
간단한 smoke test
 ↓
프로덕션 배포

로그/모니터링

구분추적 내용
애플리케이션 로그로그인 실패, 업로드 실패, AI 처리 오류
성능 모니터링API 응답 시간, 작업 큐 대기 시간
오류 추적프론트엔드/백엔드 예외 발생 알림
사용량 모니터링API 호출량, 파일 저장 용량, AI 비용

백업과 기본 보안

  • DB 자동 백업 설정
  • 업로드 파일 보관 기간 정책 설정
  • 관리자 페이지 접근 제한
  • 환경변수와 API 키는 코드에 저장하지 않음
  • 파일 업로드 확장자와 용량 제한
  • 사용자별 데이터 접근 권한 검증

클라이언트 전달 산출물

  • 배포 URL
  • 관리자 접속 URL
  • 도메인/DNS 설정 내역
  • 서버/DB/스토리지 계정 인수인계
  • 환경변수 목록
  • 장애 발생 시 확인해야 할 로그 위치
