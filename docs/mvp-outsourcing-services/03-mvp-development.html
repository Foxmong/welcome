03 MVP Development

MVP 개발 예시

기획과 디자인을 바탕으로 실제 사용자가 접속해 핵심 기능을 사용할 수 있는 첫 제품을 구현합니다.

웹앱 개발

화면/기능예시 구현
랜딩페이지서비스 가치, 사용 예시, CTA, 가격 대기 안내
회원가입/로그인이메일 가입, 로그인, 로그아웃, 비밀번호 재설정
대시보드최근 회의록, 처리 상태, 이번 달 생성 건수
회의록 생성회의 제목 입력, 파일 업로드, 생성 버튼
회의록 상세요약, 결정사항, 액션아이템, 원문 텍스트
검색/필터회의 제목, 날짜, 처리 상태로 필터링

모바일앱 개발 범위 예시

MVP에서는 보통 모바일앱보다 반응형 웹을 먼저 추천합니다. 다만 클라이언트가 앱이 꼭 필요하면 아래 범위로 축소합니다.

  • 로그인/회원가입
  • 회의록 목록 조회
  • 휴대폰 파일 선택 후 업로드
  • 회의록 상세 확인
  • 푸시 알림: 회의록 생성 완료 알림
초기 앱은 “조회와 업로드 중심”으로 제한하고, 고급 편집 기능은 웹에서 처리하도록 설계할 수 있습니다.

관리자 페이지 개발

관리 기능예시
사용자 목록가입일, 이메일, 사용량, 상태 확인
회의록 처리 현황성공/실패 건수, 실패 사유 확인
파일 처리 로그업로드 파일명, 용량, 처리 시간 확인
요금제 수동 조정베타 사용자에게 무료 사용량 부여
공지 관리서비스 점검 또는 업데이트 안내

알림/문의/대시보드 예시

항목예시
알림 기능회의록 생성 완료 이메일, 실패 알림, 사용량 초과 알림
문의 기능문의 폼, 답변 받을 이메일, 첨부 파일, 관리자 확인 상태
대시보드/통계생성 회의록 수, 평균 처리 시간, 남은 무료 사용량
예약/주문 기능이 서비스에서는 MVP 범위 제외. 필요 시 데모 신청 예약 기능으로 대체

클라이언트 제안 문구

MVP 개발 단계에서는 웹 기반으로 핵심 기능을 우선 구현합니다. 사용자는 가입 후 회의 파일을 업로드하고, AI가 생성한 회의록을 확인·수정·복사할 수 있습니다. 관리자는 사용자와 처리 실패 내역을 확인할 수 있습니다.
