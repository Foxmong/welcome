기획/요구사항 정리 예시

막연한 아이디어를 “무엇을 만들고, 무엇은 제외하며, 어떤 순서로 검증할지”로 바꾸는 단계입니다.

아이디어 구체화

초기 아이디어: 회의 녹음 파일을 올리면 AI가 회의록을 자동으로 정리해주는 서비스

구체화된 설명: 사용자가 회의 녹음 파일을 업로드하면 음성을 텍스트로 변환하고, AI가 핵심 논의사항·결정사항·액션아이템·담당자·마감일을 정리합니다.

항목예시
타깃 고객스타트업 팀, 영업팀, 컨설팅 회사, 프로젝트 매니저
해결 문제회의록 작성 시간이 오래 걸리고, 결정사항과 담당자가 누락됨
핵심 가치회의 후 정리 시간을 줄이고 후속 업무를 명확히 함

핵심 기능 정의

기능설명
회원가입/로그인이메일 기반 계정 생성 및 로그인
녹음 파일 업로드mp3, m4a, wav 파일 업로드
음성 텍스트 변환업로드 파일을 텍스트로 변환
AI 회의록 요약논의사항, 결정사항, 액션아이템 추출
회의록 저장/조회계정별 회의록 목록과 상세 화면 제공
복사/다운로드회의록을 복사하거나 markdown/pdf로 다운로드

MVP에서 제외할 기능

제외 기능제외 이유
실시간 회의 녹음초기 개발 복잡도가 높아 업로드 방식으로 먼저 검증
Zoom/Google Meet 연동핵심 가치 검증 이후 확장
팀 초대/권한 관리개인 사용자 사용성을 먼저 검증
결제/구독무료 베타 이후 유료화 검증
모바일 앱반응형 웹으로 먼저 출시

사용자 시나리오

1. 사용자가 회원가입을 한다.
2. 로그인 후 “새 회의록 만들기”를 클릭한다.
3. 회의 녹음 파일을 업로드한다.
4. 서비스가 음성을 텍스트로 변환한다.
5. AI가 회의록을 요약한다.
6. 사용자는 결과를 확인하고 필요한 부분을 수정한다.
7. 회의록을 복사하거나 다운로드한다.
8. 이후 회의록 목록에서 다시 조회한다.

기능 우선순위

우선순위기능이유
Must회원가입/로그인사용자별 회의록 저장 필요
Must파일 업로드서비스 핵심 진입 기능
Must음성 텍스트 변환회의록 생성의 기반
MustAI 요약서비스 핵심 가치

CouldPDF 다운로드있으면 좋지만 초기 필수 아님
Won't실시간 녹음MVP 범위 제외

클라이언트 전달 요약

AI 회의록 MVP의 1차 범위는 회원가입, 파일 업로드, 음성 텍스트 변환, AI 요약, 회의록 조회/수정/복사까지입니다. 실시간 녹음, 화상회의 연동, 팀 권한, 결제는 초기 검증 후 단계적으로 추가합니다.
