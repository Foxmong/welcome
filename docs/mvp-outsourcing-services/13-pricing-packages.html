1인 MVP 외주 패키지 요금 예시

AI 보조를 활용하는 1인 외주 운영자가 크몽 같은 플랫폼에서 판매하기 쉬운 고정가 패키지 기준입니다. 범위가 커지는 기능은 별도 견적으로 분리합니다.

판매 패키지 요약

패키지권장가주요 포함 범위추천 고객
아이디어 정리30만~70만 원요구사항 정리, 기능 우선순위, MVP 범위표아직 만들 범위가 불명확한 고객
랜딩 검증80만~180만 원랜딩 1~3페이지, 신청폼, GA4, 전환 추적개발 전 수요를 보고 싶은 고객

  • “AI 도움으로 빠르게 만드는 MVP 기획서/요구사항 정의서”
  • “스타트업 MVP 랜딩페이지와 대기자 모집 폼 제작”
  • “Figma 기반 MVP 화면설계와 클릭형 프로토타입 제작”
  • “노코드로 빠르게 검증하는 SaaS MVP 제작”
  • “1인 개발자가 만드는 웹앱 MVP 개발 패키지”
  • “OpenAI API 연동 AI 서비스 MVP 개발”

1인 운영 시 가격 원칙

  • 상담/기획 상품은 낮은 진입가로 두고, 개발은 반드시 범위 확정 후 견적화합니다.
  • 결제, 인증, 파일 업로드, AI, 외부 API는 고정가에 무리하게 포함하지 않습니다.
  • 서버비, API비, 도메인비, PG 수수료는 클라이언트 부담으로 명시합니다.
  • 수정 횟수는 패키지별로 제한하고, 범위 변경은 추가 견적으로 처리합니다.
  • 원본 소스코드 인도, 저작권 양도, 유지보수 포함 여부를 계약서에 분리 표기합니다.
