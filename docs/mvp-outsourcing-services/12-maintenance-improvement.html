유지보수/개선 예시

출시 후 발생하는 버그, 운영 이슈, 사용자 피드백, 성능 문제를 관리하고 제품을 개선합니다.

월 유지보수 범위 예시

항목예시
버그 수정업로드 실패, 로그인 오류, UI 깨짐, AI 결과 저장 실패
서버 관리서버 상태 확인, DB 용량 확인, SSL 만료 확인
긴급 장애 대응서비스 접속 불가, 결제 오류, AI API 장애 우회
데이터 백업백업 정상 생성 여부 확인, 복구 절차 점검
보안 업데이트라이브러리 보안 패치, 관리자 권한 점검

기능 개선 예시

피드백개선 기능
회의록을 팀원과 공유하고 싶다공유 링크 기능 추가
액션아이템만 따로 보고 싶다액션아이템 대시보드 추가
AI 결과가 너무 길다요약 길이 선택 옵션 추가
지난 회의 내용을 찾기 어렵다키워드 검색과 태그 기능 추가
기업 보안 검토가 필요하다파일 보관 기간 설정과 삭제 요청 기능 추가

성능 개선 예시

  • 긴 파일 처리 시간을 줄이기 위해 분할 처리 적용
  • 회의록 목록 페이지에 페이지네이션 적용
  • 자주 조회하는 회의록 캐싱
  • AI API 호출 비용을 줄이기 위한 프롬프트 최적화
  • 파일 업로드를 직접 서버 경유가 아닌 스토리지 직접 업로드 방식으로 개선

클라이언트 제안 문구

MVP 출시 후에는 사용자 피드백을 기반으로 기능 우선순위를 재정리합니다. 유지보수 계약에는 버그 수정, 서버 점검, 장애 대응, 백업 확인이 포함되며, 신규 기능 개발은 별도 범위로 산정합니다.
