# Interview Checklist

각 질문마다 아래 5개 상태를 확인합니다.

- [ ] 키워드를 알고 있다.
- [ ] 30초 답변이 가능하다.
- [ ] 1분 답변이 가능하다.
- [ ] 코드 예제를 작성할 수 있다.
- [ ] 꼬리 질문에 답할 수 있다.

## Swift

- [ ] let과 var
- [ ] 값 타입과 참조 타입
- [ ] Struct와 Class
- [ ] Optional과 Optional Binding
- [ ] Closure와 Escaping Closure
- [ ] Protocol과 Extension
- [ ] Generic
- [ ] Error Handling
- [ ] ARC, weak, unowned
- [ ] Equatable, Hashable, Codable
- [ ] 접근 제어
- [ ] Copy-on-Write

## SwiftUI

- [ ] View와 body, some View
- [ ] State와 Binding
- [ ] Observable와 Environment
- [ ] View 생명주기
- [ ] NavigationStack
- [ ] Identifiable, List, ForEach
- [ ] SwiftUI 렌더링 방식
- [ ] 컴포넌트 분리
- [ ] UIKit과 SwiftUI 차이

## iOS / Network / Concurrency / Architecture

- [ ] 앱 생명주기, Main Thread, RunLoop
- [ ] URLSession, HTTP, REST, JSON, Codable
- [ ] async/await, Task, MainActor, Actor, Race Condition
- [ ] MVC, MVVM, Repository, Service, Dependency Injection
- [ ] UserDefaults, Keychain, SwiftData, Core Data
- [ ] 테스트 가능한 코드와 Mock 설계
