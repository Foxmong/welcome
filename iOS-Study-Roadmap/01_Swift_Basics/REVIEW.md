# Swift Basics 복습

## 핵심 개념 10개

1. 학습은 읽기, 타이핑, 설명, 복습 순서로 진행한다.
2. Swift는 언어이고 SwiftUI는 UI 프레임워크다.
3. Xcode는 작성, 빌드, 실행, 디버깅 도구다.
4. SwiftUI 앱은 `App` 진입점에서 시작한다.
5. `let`은 상수, `var`는 변수다.
6. 기본 타입은 앱 데이터를 안전하게 표현한다.
7. 조건문은 화면 분기를 만든다.
8. 반복문과 `ForEach`는 목록 UI를 만든다.
9. 함수는 로직을 재사용하게 한다.
10. Optional은 값 없음 가능성을 안전하게 표현한다.

## 빈칸 채우기

* SwiftUI에서 화면 내부 상태는 `____`로 선언한다.
* 값이 없을 수 있는 타입은 `____`이다.

## OX 문제

* `let`으로 선언한 값은 나중에 변경할 수 있다. (O/X)
* `List`는 배열 데이터를 화면 목록으로 보여줄 때 자주 사용한다. (O/X)

## 코드 결과 예측

```swift
let name: String? = nil
print(name ?? "Guest")
```

## 오류 코드 수정

```swift
let count = 0
count += 1
```
