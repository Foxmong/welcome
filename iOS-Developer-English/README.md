# iOS Developer English

Swift, SwiftUI, Xcode를 공부하는 동안 반복해서 만나는 개발 영어를 빠르게 읽고 이해하기 위한 한국어 기반 학습 자료입니다. 목표는 영어 시험이 아니라 코드 이름, 오류 메시지, 공식 문서, GitHub, 기술 면접에서 멈추지 않는 것입니다.

## 학습 흐름

```text
개발 화면이나 코드에서 영어 발견
→ 단어를 구성 요소로 분해
→ 개발 문맥에서의 의미 확인
→ 실제 코드와 Xcode 화면에서 사용
→ 오류 메시지 해석
→ 검색어로 변환
→ 면접 표현으로 확장
```

## 하루 30~45분 루틴

1. 신규 단어 10개를 코드 이름으로 읽기
2. Swift 또는 SwiftUI 예제에서 단어 확인
3. 오류 메시지 한 개를 5단계로 분석
4. 한국어 문제를 영어 검색어 3개로 바꾸기
5. 플래시카드로 복습
