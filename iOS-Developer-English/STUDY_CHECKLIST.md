# Study Checklist

## 1주차: 핵심 개발 영어

* [ ] 개발 동사 60개를 함수 이름으로 읽는다.
* [ ] 개발 명사 60개를 Swift 문맥에서 설명한다.
* [ ] 상태 형용사 25개를 UI 상태와 연결한다.
* [ ] 오류/검증 단어로 오류 메시지를 5개 분석한다.
* [ ] 접두사와 접미사로 긴 단어를 분해한다.

## 2주차: Swift 키워드

* [ ] `let`과 `var`의 차이를 영어로 말한다.
* [ ] `throws`, `try`, `catch`가 오류 흐름을 만드는 방식을 설명한다.
* [ ] `async`와 `await`가 비동기 흐름을 나타냄을 이해한다.
* [ ] 접근 제어 키워드를 public/internal/private 순서로 비교한다.
